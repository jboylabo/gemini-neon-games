# NEON OVERDRIVE — Three.js 3D Cyber Car Game

Three.js + React + TypeScript + Vite で構築した、ブラウザで動作するサイバーパンク調 3D カーゲームです。
プレイヤー車両には **Mercedes-Benz Gクラス（AMG G63 スタイル）** の 3D モデルを採用しています。

## 主な機能

- **Mercedes-Benz Gクラス 3D モデル**: 丸型 LED デイライト、パナメリカーナグリル＆スリーポインテッドスター、オーバーフェンダー、背面スペアタイヤカバー、AMG マルチスポークホイール、サイド出しデュアルエキゾーストを搭載
- **Three.js 3D ワールド**: ネオンハイウェイ、スカイスクレイパー、シンセウェーブ・サン、パーティクル演出、3種類のカメラ視点
- **メニュー & カスタマイズ**: 3つのゲームモード（NEON CITY / CYBER RUSH / ENDLESS CHILL）と 5種類のボディカラー（マットブラック標準・背景の 3D 車両へ即時反映）
- **エンタメギミック**:
  - **ニトロスマッシュ**: ニトロ発動中は無敵になり、ライバル車を弾き飛ばしてボーナス獲得
  - **ニアミスボーナス**: 障害物のギリギリ横をすり抜けるとコンボ倍率アップ＆ニトロ回復
  - **ネオンジャンプ台**: スロープで豪快に空中ジャンプし、前方の車両を飛び越える
  - **エネルギーシールド**: 1回分の衝突を無効化するホログラムバリア
- **Web Audio API シンセウェーブ BGM & SE**: 外部音声ファイル不要でシンセウェーブ BGM をリアルタイム生成・ループ再生。画面右上のボタンまたは `M` キーでいつでも BGM のオン/オフを切り替え可能

## ローカル実行・ビルド手順（pnpm）

### 1. 依存パッケージのインストール

```bash
pnpm install
```

### 2. 開発サーバーで起動する場合

```bash
pnpm dev
```

起動後、ブラウザで `http://localhost:5173/` を開いてください。

### 3. プロダクションビルドしてローカル確認する場合

```bash
pnpm build
pnpm preview
```

`vite.config.ts` で開発・プレビューともにポート `5173` に設定しているため、`pnpm preview` でも `http://localhost:5173/` で確認できます。

## 操作方法

| キー | 操作 |
| --- | --- |
| `← / →` または `A / D` | 左右ステアリング |
| `↑ / ↓` または `W / S` | アクセル / ブレーキ |
| `Space` または `Shift` | ニトロブースト（ゲージ 25% 以上） |
| `C` | カメラ視点切替（チェイス / ダイナミック / ボンネット） |
| `P` または `Esc` | ポーズ / 操作説明表示 |
| `M` | BGM オン / オフ切替 |
